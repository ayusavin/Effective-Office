# Applications Overview

## Meeting Room Tablet App

### Purpose
Enable quick and efficient meeting room booking directly from tablet devices placed in meeting rooms.

### Key Features
- Real-time room availability display
- Quick booking (single tap)
- Time-specific reservations
- Booking cancellation
- Early room release
- Google Calendar integration

### Target Platform
- Android tablets

## TV App

### Purpose
Display corporate information, employee highlights, and events on TV screens throughout the office.

### Key Features
- **Stories**: Employee birthdays, anniversaries, new hires, congratulations
- **Leaderboard**: Duolingo, sports, internal currency stats
- **Events**: Upcoming events with QR codes for registration
- **Photo Slideshow**: Corporate photos grouped by albums
- **Autoplay**: Automatic screen switching
- **Remote Control**: Navigation via remote

### Target Platform
- Android TV

## SMS Router

### Purpose
Intercept incoming SMS messages and forward them to configured webhooks for integration with other systems.

### Key Features
- SMS interception
- Webhook forwarding
- Per-SIM configuration
- Delivery logging (Room database)
- Settings UI for webhook configuration

### Target Platform
- Android mobile devices

## Common Goals
- Simplify office work through automation
- Minimize use of non-Kotlin technologies
- Leverage Kotlin Multiplatform for code sharing
