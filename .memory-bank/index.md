## About This Project

**Effective Office** is a Kotlin Multiplatform project designed to automate and simplify everyday office work.

### Applications
- **Meeting Room Tablet App** - Real-time meeting room booking with Google Calendar integration
- **TV App** - Corporate information display (events, leaderboards, photos, employee highlights)
- **SMS Router** - SMS interception and webhook forwarding

## For AI Agents & Developers

### How to Use Memory Bank

**Before Starting Work:**
1. ✅ Read relevant sections from `.memory-bank/` 
2. ✅ Check architecture patterns and conventions
3. ✅ Review active tasks in `tasks/` directory
4. ✅ Ensure your approach aligns with documented practices

**During Development:**
- Follow conventions in [Development Conventions](./steerings/development-conventions.md)
- Use tech stack versions from [Tech Stack](./tech-details/tech-stack.md)
- Maintain architecture patterns from [Architecture](./tech-details/architecture.md)
- Write tests per [Testing Conventions](./steerings/testing-conventions.md)

**After Significant Changes:**
- Consider if Memory Bank needs updating (see [.cursor/rules/memory-bank.mdc](../.cursor/rules/memory-bank.mdc))
- Only suggest updates for importance ≥ 2 (architectural changes, new conventions, API changes)
- Use the Memory Bank Steward format for updates
